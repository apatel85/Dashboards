🚩 QA Capture — Settings

Step 1 — Connect your GitHub

QA Capture files bugs into the team's dashboard repo on GitHub. Your token is how GitHub knows it's you — your name goes on everything you file, and you can only delete your own bugs. The token stays on this device and is only ever sent to GitHub.

Create your token (about 2 minutes):

  1. Open GitHub's token page ↗ and sign in.
  2. Name it QA Capture.
  3. Under Repository access, choose Only select repositories → Dashboards. (Don't see it? Ask Ankit to add you as a collaborator on that repo first.)
  4. Under Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it here:

The repo is pre-filled with the team dashboard repo — leave it as is unless your admin tells you otherwise. Bugs you file appear on the dashboard automatically after its next refresh.

Projects → dashboards

Each project watches one or more sites (one host per line — a bare domain also matches its subdomains) and files flagged bugs into its dashboard folder in the repo.

Filed issues

View and edit bugs previously filed with the extension. Edits save to the repo immediately; the dashboard view catches up on its next refresh.
