🚩 QA Capture — Settings

GitHub

The token is stored only in this browser (extension storage). It is never sent anywhere except api.github.com.

Projects → dashboards

Each project watches one or more sites (one host per line — a bare domain also matches its subdomains) and files flagged bugs into its dashboard folder in the repo.

Filed issues

View and edit bugs previously filed with the extension. Edits update the bug file in the repo; the dashboard rebuilds within ~10 minutes.
