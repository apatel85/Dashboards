How this works

Research is commissioned in the Market Research chat: hand over one particular website, company, or product, and it gets a full in-depth research pass — current product analysis, market landscape, competitor research, SWOT, Quixera leverage at a reasonable cost, and a build / extend / new-tool decision.

Each finished research project becomes a tab in this dashboard. Tabs follow the same fixed order: Verdict, Product snapshot, Market landscape, Competitor comparison, SWOT, Red flags, Opportunities, Quixera path, New-tool decision, Sources, Open questions.

Tabs can be shared individually. Every research tab has a Download PDF button (prints just that tab) and a Copy share link button (a link that opens this dashboard showing only the chosen tabs).

A note on the password gate: this dashboard is protected by a shared password, which keeps casual visitors out. It is not true login security — the page content technically lives in the site's files, so it will not stop someone determined. If any research is ever genuinely sensitive, ask for proper login-based access instead.
