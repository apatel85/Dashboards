# Deployment Guide - Render.com

Deploy as a live password-protected web app in ~5 minutes.

## Steps

### 1. Create Render Account
https://render.com (free tier works)

### 2. Deploy via Blueprint
1. Render dashboard -> New -> Blueprint
2. Connect GitHub -> select `apatel85/Dashboards`
3. Render detects `CongressTradeTracker/render.yaml` automatically
4. Click Apply

### 3. Set Admin Password
1. Service -> Environment -> find ADMIN_PASSWORD -> Edit
2. Set a strong password
3. Save (Render redeploys automatically)

### 4. Initialize the Database
In Render Shell tab:
```bash
cd /opt/render/project/src/CongressTradeTracker
mkdir -p output
python -c "import sqlite3; c=sqlite3.connect('output/master_trades.db'); c.executescript(open('schema.sql').read()); c.commit(); print('done')"
```

### 5. Access the App
```
https://congress-trade-tracker.onrender.com
```
Username: admin
Password: what you set in step 3

## Environment Variables

| Variable | Description |
|----------|-------------|
| SECRET_KEY | Auto-generated by Render |
| ADMIN_USERNAME | Login username (default: admin) |
| ADMIN_PASSWORD | **Set manually - never commit to Git** |
| DB_PATH | output/master_trades.db |

## ETL Scheduling on Render

### Option A - Render Cron Job
1. New -> Cron Job -> same repo, rootDir=CongressTradeTracker
2. Schedule: `0 */6 * * *`
3. Command: `python scheduler.py --once`

### Option B - GitHub Actions
`.github/workflows/refresh.yml` already runs every 6 hours.

## Local Dev
```bash
cd CongressTradeTracker
pip install -r requirements.txt
mkdir -p output
python -c "import sqlite3; c=sqlite3.connect('output/master_trades.db'); c.executescript(open('schema.sql').read()); c.commit()"
python app.py
# http://localhost:5000  login: admin / ChangeMe123!
```
