VoiceFlow

Hold a key, speak, and clean text appears in the app you are typing in. Your audio stays on your computer.

Download for Windows

Looking up the latest version…

Windows will warn you. The app is not code-signed (certificates cost money and this project is free), so SmartScreen says “Windows protected your PC”. Choose More info then Run anyway. Some antivirus tools may flag it too, because it uses a global keyboard hook and synthesised keystrokes to type into other apps. The source is public, and each download has a SHA-256 checksum in the release notes.

First run

  1. Pick your microphone; a level bar shows it can hear you.
  2. Download the speech model once (about 160 MB). After that everything works offline.
  3. Click into any app, hold F9, speak, release.

Keys

F9 holdtalk; release to insert
F9 double-taphands-free; tap again to stop
Esccancel
Ctrl+Alt+Zundo the last insertion
Ctrl+Alt+Pnext style (Casual, Business, Professional, AI Prompting)

Privacy

No accounts, no analytics. Audio never leaves your computer. Optional “Cloud polish” (off by default) sends only text, through a private proxy, and no API key is ever stored in the app.
