## Decisions (standing — don't re-litigate)
- **No API key in the app, ever.** The Gemini key is a server-side secret. Chain: GitHub secret `GEMINI_API_KEY` → workflow `voiceflow-polish-deploy.yml` → Supabase function secret → Edge Function `voiceflow-polish` → Gemini. The app only holds Supabase's public anon key and calls `ProxyPolishAdapter`. (Overrides spec §7.3 "enter keys in the app"; direct `GeminiAdapter` remains for tests/Ollama-style use.)
- Cloud polish is off by default and needs consent (`Settings.cloudActive`).
- iOS out of scope. English first. Flutter pinned 3.50.0 (Dart 3.14).
- Golden fixtures live in `packages/core/test_fixtures/formatting/<profile>/cases.json`.

Release APK (x86_64, debug-signed) on a KVM API-30 emulator: Kotlin `InputMethodService` enabled+selected via `ime set`, focused a native `EditText`, IME called Dart through a headless `FlutterEngine` (`package:voiceflow_app/ime_main.dart` → `RuleFormatter` from `packages/core`, assets from the bundle), committed `We shipped 12 features.` Verified from the app side: `uiautomator` shows the EditText `text="We shipped 12 features."`; IME read-back matched too.

Decision: S3 primary design (headless engine in the IME) stands; bound-service fallback not needed.
- **Not proven:** real phone performance; STT (sherpa-onnx) on Android/emulator (S1-Android still NOT-VERIFIED) and its memory when the model is loaded; microphone capture; Gboard-style behaviour in real apps (A-checklist).
- **Gotchas recorded:** (1) a secondary Dart entrypoint library must be imported by `main.dart` or release/AOT builds fail with `library ... not found`; (2) `logcat -s S3:I S3:E` shows only errors — use `S3:I '*:S'`; (3) `adb shell` strips host quotes — wrap the remote command in quotes; (4) piping to `tee` hid failures — use `pipefail`.
- **Must fix before any release:** `TestActivity`, the exported `dev.voiceflow.S3_FORMAT` broadcast receiver in `VoiceFlowIME`, and `ImeEngine` test hooks are spike code in `main` sources. Any app on the phone could inject text through that receiver. Move to a debug-only source set before M2 ships.
