Proxy Configuration🔒 Keys stored in Supabase Secrets
⚠
How to add your real API keys: Go to Supabase Dashboard → Edge Functions → Secrets and add: HUD_API_KEY, CENSUS_API_KEY, APILLOW_API_KEY. Keys are encrypted and never exposed to the browser.
Setup Guide
1. Census ACS
Get free key at census.gov. Add as CENSUS_API_KEY in Supabase.
2. HUD FMR
Register at huduser.gov. Add as HUD_API_KEY in Supabase.
3. APIllow
Get 50 free req/month at apillow.co. Add as APILLOW_API_KEY in Supabase.
4. AirDNA
No key needed. Proxy-airdna function handles it automatically.
5. Supabase Secrets
Go to Project Settings → Edge Functions to add all secrets.
6. CORS
Set ALLOWED_ORIGIN=https://apatel85.github.io in Supabase secrets to lock proxy to your domain.
