⚠
HTTP 403 — RentCast API Forbidden / Quota Exceeded Your API key is recognised but the request was rejected. Common causes:
• Plan limit reached — free tier allows 50 calls/month. Check app.rentcast.io ↗
• Wrong endpoint access — your plan may not include the /listings/sale endpoint. Upgrade to a paid plan.
• IP restriction — some keys are locked to specific IPs. Verify in RentCast dashboard.
Until resolved, the sync engine returns MODEL data (generated estimates). Values shown are statistically plausible but NOT live market prices.
