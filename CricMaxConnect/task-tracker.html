How this tracker stays fresh — no AI agent needed

  • Reads the sheet on every visit (cache-busted fetch of all 6 tabs), plus an automatic refresh every 24 hours while the page stays open, plus a refresh whenever you return to the tab. Force Refresh re-reads everything immediately.
  • Reminders in the page: Overdue and Due-soon (7 days) alerts on the Overview, computed from real due dates in the sheet. Enable reminders also turns on browser notifications while the page is open.
  • Daily email digest (optional): the companion Apps Script sends an overdue + due-soon email every morning — set it up once (steps below) and it runs on Google's servers, not here.
  • Two-way editing works through the same Apps Script, deployed once as a web app. Until it is connected, this page is read-only and editing controls are disabled.

Two-way sync bridge

Bridge: not configured (read-only mode).

  1. Open the sheet → Extensions → Apps Script. Copy in tracker-apps-script.gs (in this same folder on GitHub).
  2. Set the recipient emails at the top of the script, and optionally a BRIDGE_TOKEN in Script Properties for a shared secret.
  3. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone. Copy the /exec URL and paste it above.
  4. For the daily email: in Apps Script → Triggers → Add trigger → sendDailyDigest → Time-driven → Day timer → 8am–9am.

Note: the bridge URL is visible to anyone who opens this page, so it is protected by obscurity, not real security. Do not put sensitive personal data in this tracker. Every edit is recorded in the sheet's version history.
