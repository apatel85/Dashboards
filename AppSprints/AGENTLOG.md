# AGENTLOG — App Sprints

## 2026-11-12 — v1.0.0 — Intake pipeline built

- **Ankit's request:** Build the App Sprints intake pipeline — an intake form, a daily watcher, and one folder per request — so ideas go through a Phase 0 research sprint and a Research Receipt before design starts.
- **What changed:** v1.0.0. New intake app (`index.html`): plain-language intro with the longer how-it-works detail in a collapsed section; Step 1 three classifier questions as large tap targets; Step 2 five intake questions with the one-sentence description required; Step 3 branching follow-ups (you/team, public, and up to 4 roles) shown only when relevant; auto-suggested kebab-case intake name (editable); submit generates a JSON brief and a plain-text brief, each with its own Copy button, plus instructions to paste it in the App Sprints side chat. New root `README.md` (pipeline, watcher, manual-request steps, folder-per-request structure). Repo structure set: `sprints/<intake-name>/` holds `intake.json` and `research-receipt.md`; actual apps are built under the main Dashboards folder, never inside AppSprints.
- **Verification:** Checked by the builder on this machine — HTML tags balanced (verified with a parser), inline script passes `node --check` on the extracted script, all branching logic wired to real element IDs (`branch-personal`, `branch-public`, `branch-roles`, `audience-group`, `user-types-group`, `frequency-group`, `device-group`, `roles-list`, `add-role`, `intake-name`, `q-what`), form validates the one-sentence description before generating a brief, layout uses a single 640px column with no fixed widths.
